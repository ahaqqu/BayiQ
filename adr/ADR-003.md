# ADR-003: Local-first CRDT sync to D1 for anonymous sessions

**Status:** accepted  
**Date:** 2026-08-09

## Context

The app is the source of truth in the prototype (`localStorage`). The architecture requires the client store to remain the source of truth, with opportunistic server sync.

## Decision

Rebuild `packages/local-first` for immunization records. The client IndexedDB store owns Child and Record data; an elected leader syncs a CRDT snapshot to D1 per anonymous session. Sync is opportunistic, delta-based, and non-blocking.

## Rationale

- Exercises the local-first architecture from day one.
- Proves the D1/ObjectStore/Logger adapters with real data.
- Enables future multi-device access once real auth is added.
- Data volume per user is tiny (a few KB), well inside free-tier write limits.

## Consequences

- `packages/local-first` must drop the upstream Notes CRDT mapping and adopt Child/Record mappings.
- Conflict resolution is per-record LWW, acceptable for single-user data.
- The server must validate incoming CRDT payloads against Valibot contracts.
